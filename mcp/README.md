# Гроші → Claude (MCP)

Дає Claude прямий доступ до даних вашої апки: портфель, дохідність, угоди,
дивіденди, доходи-витрати, підписки, ФОП і рахунки клієнтам. Головне
призначення — розбір портфеля й поради, для яких потрібні реальні цифри,
а не переказ по памʼяті.

**Читає, не пише.** У сервері фізично немає коду запису — зіпсувати дані
апки він не може навіть помилково. Токенів (Monobank, IBKR, Binance) не
торкається: вони лежать у Диспетчері облікових даних Windows, а не у
файлах, і мережевого коду в сервері немає взагалі.

---

## Встановлення (3 хвилини)

**1. Потрібен Node.js 18+.** Перевірте у PowerShell:

```
node --version
```

Немає — поставте з nodejs.org (LTS), потім перезапустіть термінал.

**2. Покладіть теку.** Скопіюйте `groshi-mcp` (з файлами `groshi-mcp.js`
і `mononorm.js`) кудись, звідки її не зітруть, наприклад:

```
C:\Groshi\groshi-mcp\
```

**3. Перевірте, що сервер бачить дані:**

```
node "C:\Groshi\groshi-mcp\selftest.js"
```

Має вивести теку даних і кількість позицій, операцій, знімків. Якщо
порожньо — див. «Якщо щось не так» нижче.

**4. Підключіть у Claude Desktop.** Файл конфігурації:

```
%APPDATA%\Claude\claude_desktop_config.json
```

Якщо файлу немає — створіть. Якщо є — додайте розділ `groshi` всередину
наявного `mcpServers`, не затираючи інші сервери:

```json
{
  "mcpServers": {
    "groshi": {
      "command": "node",
      "args": ["C:\\Groshi\\groshi-mcp\\groshi-mcp.js"]
    }
  }
}
```

Зверніть увагу на подвійні зворотні слеші — у JSON інакше не можна.

**5. Повністю закрийте Claude Desktop** (з трею теж) і запустіть знову.
У вікні чату з'явиться значок інструментів, а серед них — `groshi`.

## Що можна питати

- «Розбери мій портфель: концентрація, сектори, що виглядає перекошено»
- «Скільки я реально заробив за рік і скільки з цього — просто внески?»
- «Яка в мене дивідендна дохідність на вкладене і скільки це на місяць?»
- «Я хочу докупити на 500 $ — що логічніше взяти, виходячи з мого перекосу?»
- «Скільки я можу відкладати щомісяця, не чіпаючи подушку?»
- «Покажи мої угоди по MSFT і чи вдало я входив»
- «Які рахунки клієнтам ще не оплачені і скільки податків за квартал?»

Порада: Claude бачить лише те, що є у файлах. Ринкові новини, ціни
конкурентів чи звіти компаній він додасть уже пошуком в інтернеті —
просто попросіть «звір це з тим, що зараз на ринку».

## Інструменти (10)

| Інструмент | Що дає |
|---|---|
| `groshi_status` | Тека, свіжість даних, обсяги. Перший при будь-яких дивацтвах |
| `portfolio` | Позиції, частки, P&L, сектори, концентрація, цілі ребалансу, watchlist, ваші тези |
| `portfolio_performance` | TWR, річними, XIRR, просадка, внески, крива вартості |
| `portfolio_trades` | Угоди з фільтрами, реалізований P&L по роках, % прибуткових |
| `portfolio_dividends` | Отримані по роках і тікерах + прогноз на 12 місяців |
| `position` | Один папір детально: угоди, фундаментал, дивіденди, теза |
| `money_flow` | Баланси, капітал, доходи-витрати по місяцях, скільки лишається |
| `transactions` | Пошук операцій банку з фільтрами |
| `subscriptions` | Підписки, сума на місяць і рік |
| `fop_and_invoices` | ФОП по кварталах, податки, неоплачені рахунки |

## Якщо щось не так

**«Інвестиційних даних немає»** — сервер читає `inv_cache.json`, який
пише сама апка. Розібрати сирий XML брокера він не може: для цього
потрібен браузерний DOMParser. Тож після синхронізації з IBKR **відкрийте
апку хоч раз** — вона перезапише кеш, і сервер побачить свіже.
Потрібна версія апки **1.28.1 або новіша** (у 1.26–1.28.0 кеш через
незареєстровану команду не писався).

**Операцій 0** — поруч із `groshi-mcp.js` має лежати `mononorm.js`. Він у
комплекті; якщо ви оновили апку до версії, де формат банку змінився,
візьміть свіжий `mononorm.js` із `Groshi_desktop_src.zip` (тека `dist`).

**Сервер не бачить теку** — задайте її вручну в конфігурації:

```json
{
  "mcpServers": {
    "groshi": {
      "command": "node",
      "args": ["C:\\Groshi\\groshi-mcp\\groshi-mcp.js"],
      "env": { "GROSHI_DIR": "C:\\Users\\ВашеІмʼя\\AppData\\Roaming\\ua.groshi.desktop" }
    }
  }
}
```

Точний шлях показує сама апка: «Ще → Апка і дані → Показати теку з даними».

**Ціни застарілі** — сервер бере їх із `quotes.json`; натисніть «Оновити
ціни» в апці.

**Claude не бачить сервер** — перевірте, що JSON валідний (кома між
серверами, подвійні слеші), і що Claude Desktop перезапущений повністю,
а не згорнутий у трей.

## Приватність

Дані нікуди не надсилаються сервером: він лише читає файли й віддає текст
Claude Desktop у відповідь на ваш запит. Що саме побачить Claude —
вирішуєте ви, ставлячи питання: без виклику інструмента він не бачить
нічого. Розмова з Claude при цьому йде звичайним каналом — те, що
потрапило у відповідь інструмента, стає частиною чату.
