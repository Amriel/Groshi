# Гроші

Десктопний застосунок особистих фінансів для України: банк, інвестиції,
підписки, ФОП і рахунки клієнтам — в одному вікні, **без сервера,
без хмари і без акаунта**. Дані лежать простими JSON-файлами на вашому
диску; ключі доступу — у Диспетчері облікових даних Windows.

> Проєкт зроблено для себе і випущено як є. Він робочий, але це не
> продукт із підтримкою: якщо щось не працює у вашому випадку —
> найшвидший шлях це полагодити самому, код для того й відкритий.

---

## Що воно вміє

**Банк.** Monobank напряму за особистим токеном: операції, баланси,
власні категорії й правила, парування переказів між своїми рахунками
(інакше місяць «витрачає» вдвічі більше). Виписку ПриватБанку можна
імпортувати файлом.

**Інвестиції.** Interactive Brokers (Flex-звіт) і Binance: позиції,
угоди, дивіденди, TWR і XIRR, максимальна просадка, дивдохідність на
вкладене, теза на кожну позицію, мітки власних угод просто на графіку
ціни. Котирування й фундаментал — Yahoo Finance.

**Підписки.** Апка сама знаходить рівні ряди списань і пропонує їх
підтвердити; свої (оренда, хостинг, готівка) додаються вручну. Суми у
валюті рахуються за живим курсом. Календар грошей зводить в один місяць
підписки, податки ФОП, дати дивідендів і очікувані оплати рахунків.

**ФОП.** Квартали, ЄП і ВЗ, дедлайни декларації та сплати, книга обліку
доходів у CSV з курсами НБУ на дати зарахувань. Групи й ставки
налаштовуються — не ФОП просто вимикає картку.

**Рахунки клієнтам.** Кошториси з погодинними й фіксованими рядками →
рахунок у HTML (укр / англ / двомовний, з податком або без, у валюті або
гривні), профілі власних реквізитів, база клієнтів, підпис зображенням.
Виставлені рахунки лягають у журнал, де апка сама звіряє їх із
зарахуваннями на рахунок і показує прострочені.

**Капітал.** Банк + інвестиції + інше майно однією цифрою, зі знімком
раз на день — за рік із цього виходить графік, якого немає в жодному
окремому джерелі.

**Режим скріншоту.** Клавіша `S` ховає всі суми крапками, лишаючи
структуру, категорії й форму графіків — щоб показати апку, не показуючи
своїх грошей.

## Приватність

- Власного сервера немає. Підключені Monobank, IBKR і Binance отримують
  запити до вашого рахунку; НБУ — валюту й дату потрібного курсу.
- Котирування, новини, логотипи, переклад і перевірка оновлень типово
  вимкнені. У **Ще → Джерела → Приватність і зовнішні сервіси** кожен
  дозвіл вмикається окремо. Yahoo отримує тікери, Parqet/GitHub/Clearbit/Google —
  тікери або домени для логотипів, Google Translate/MyMemory — заголовки
  новин. Сервери також бачать IP-адресу запиту. Власне джерело оновлень
  отримує запит до нього після дозволу оновлень.
- Токени (Monobank, IBKR Flex, Binance) — тільки в Диспетчері облікових
  даних Windows. Ні у файлах, ні в `localStorage`, ні в логах.
- Binance-ключ приймається лише з правом читання; будь-яке інше право —
  відмова.
- Тексти помилок зачищаються від параметрів запиту: мережева бібліотека
  вкладає в них повний URL разом із токеном.
- Опційний код на вхід (`Ще → Апка і дані`) — від «сів за компʼютер і
  все побачив». Це не шифрування, і так і підписано.
- JSON-файли, резервні копії та експорти містять відкриті фінансові дані.
  Хмарна тека або передавання експорту надає ці дані відповідному сервісу
  чи отримувачу. Браузерний HTML зі своїм набором даних також є приватним файлом.
- Оновлення потребують Ed25519-підпису в сусідньому `.exe.sig`; довільний
  файл із теки чи HTTPS-адреси застосунок не запустить. Це окремий захист
  від підпису Authenticode Windows.
- Перевірка перед комітом і CI відхиляє секрети, виписки та непорожні
  публічні набори даних. Налаштування — у [CONTRIBUTING.md](CONTRIBUTING.md).

## Збірка

Потрібні Node 18+, Rust і Python 3.

```bash
# 1. браузерна версія — один HTML-файл
cd app && python3 build_app.py          # → app/Groshi_app.html

# 2. десктопна: вставляє браузерний шаблон у Tauri-оболонку
cd ../desktop && python3 build_desktop.py   # → desktop/dist/index.html
npm ci
npm run build:win                        # → інсталятор у src-tauri/target/…/nsis/
```

Докладніше — [docs/ЯК_ЗІБРАТИ.md](docs/ЯК_ЗІБРАТИ.md).
Чому все влаштовано саме так — [docs/РОЗРОБКА.md](docs/РОЗРОБКА.md):
там історія кожного рішення разом із причиною.

## Дані

Репозиторій постачається **порожнім**: `app/dataset.json` і
`desktop/dist/legacy.json` — порожні масиви. Апка стартує чистою, і
майстер першого запуску веде до підключення банку. Ваші дані
зʼявляться в `%APPDATA%\ua.groshi.desktop\` або у вибраній вами теці.
Зміна теки виконується після перезапуску; старі резервні копії залишаються
на місці. Фактичну теку видно в налаштуваннях апки.

## MCP-сервер

У теці [`mcp/`](mcp/) лежить сервер, який дає Claude доступ до ваших
даних **тільки на читання**: портфель і його дохідність, угоди,
дивіденди, доходи-витрати, підписки, ФОП. Без залежностей — потрібен
лише Node. Інструкція: [mcp/README.md](mcp/README.md).
