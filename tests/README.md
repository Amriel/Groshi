# Проби

Сценарії на Playwright: відкривають зібраний файл, роблять те саме, що
робила б людина, і друкують результат. Кожна написана під конкретний
випадок і лишилась у репозиторії як сторож — щоб та сама поломка не
повернулась тихо.

```bash
npm install playwright && npx playwright install chromium
python3 app/build_app.py          # проби працюють із ЗІБРАНИМ файлом
node tests/allcheck.mjs
```

Якщо chromium уже є в системі, шлях до нього можна передати змінною:
`CHROMIUM=/usr/bin/chromium node tests/allcheck.mjs`. Якщо `playwright`
встановлено поза репозиторієм (наприклад, у робочій теці без власного
`node_modules`), шлях до модуля задає
`PLAYWRIGHT_MODULE=/шлях/до/node_modules/playwright`. Обидві змінні читають
усі проби з таблиці нижче, крім `pjstat.mjs` і `v1311.mjs`: вони
імпортують `playwright` напряму й `PLAYWRIGHT_MODULE` ігнорують.

Повний набір: `npm test` (так само його запускає CI). Python-тести:
`python -m unittest discover -s tests -p 'test_*.py' -v`.

## Playwright-проби (`*.mjs`)

| Проба | Що сторожить | Запуск |
|---|---|---|
| `ibkr-currency.mjs` | підсумковий рядок валюти у звіті IBKR не подвоює суму (25 $ готівки не стають 50) | `npm test` |
| `security.mjs` | XML і кеш безпечні, CSP блокує код і мережу, дозволи зберігаються, конкуруючий клік блокується до завершення запису | `npm test` |
| `allcheck.mjs` | 7 вкладок, тема й вибір періоду працюють без помилок у консолі (обидві збірки) | `npm test` |
| `empty.mjs` | порожня апка (свіжа установка): на кожній вкладці секція видима й непорожня, 0 помилок консолі/сторінки | `npm test` |
| `scrn.mjs` | режим скріншоту: після вмикання на кожній вкладці 0 сум із валютою, бейдж є; вимкнення прибирає маски й бейдж | `npm test` |
| `gaps.mjs` | картки не злипаються: зазор між сусідніми ≥ 8 px, злиплих 0 на кожній вкладці | `npm test` |
| `pjui.mjs` | групи клієнтів у кошторисах розділені візуально: груп ≥ 2, у кожної рамка, радіус і проміжок | `npm test` |
| `glass2.mjs` | скляний шар: привидів після скролу 0, кадрів під час руху 0, перекриттів карток 0 | `npm test` |
| `modal.mjs` | скасування, підтвердження, фокус і послідовні вікна без нативних діалогів; обхід усіх вкладок: жодного `title` поза `<iframe>`, `<input type="date">` чи `<input list>` | `npm test` |
| `pjjump.mjs` | зміна ставки й типу рядка кошторису не зсуває розмітку (0 px), меню лишається у вікні | `npm test` |
| `pjlog.mjs` | журнал кошторису: сім правок → один запис, події окремо; «Поділитись» іде через `download()` | `npm test` |
| `period.mjs` | порівняння з тим самим відрізком попереднього періоду; середнє на неповному періоді — денне (лише десктоп) | `npm test` |
| `desktop-csp.mjs` | CSP десктопа: стилі та геометрія 7 вкладок збережені, сторонній код і мережа заблоковані | `npm test`; у CI ще й окремо на Windows |
| `notrans.mjs` | перемикання вкладок не смикає розмітку: кадр через 800 мс (після навмисних ковзань підсвітки) і через 1800 мс побайтно однаковий, без `pngjs` | `npm test` |
| `pjstat.mjs` | стани проєкту: випадайка з чипа, дата оплати, KPI до й після оплати, селект у картці | `npm test` |
| `v1311.mjs` | сторож 1.31.1: фон під час скролу, маскування кошторису в режимі скріншоту, випадайка стану (частково дублює `glass2`, `scrn`, `pjstat`) | `npm test` |

**Знімки, не проби.** `node tests/helpers/synthetic.mjs` пише штучний набір,
`python app/build_app.py --data .test-artifacts/synthetic.json --out
.test-artifacts/synthetic_app.html` збирає з ним окремий HTML, а
`node tests/snap.mjs <мітка>` робить 42 знімки (7 вкладок × 2 теми × 3 ширини)
у `.test-artifacts/snap-<мітка>/`. Це інструмент для порівняння вигляду до й
після змін, він нічого не стверджує й у `npm test` не входить.

## Python-тести (`test_*.py`)

Запускаються в CI кроком `unittest` перед `npm test`.

| Тест | Що сторожить |
|---|---|
| `test_build_security.py` | штучні дані не ламають структуру зібраного HTML; CSP іде перед ресурсами; хеш скрипта залежить від приватного знімка |
| `test_privacy_check.py` | `scripts/privacy_check.py` відхиляє приватні файли й секрети (не друкуючи значень), пропускає порожні публічні seed-файли |
| `test_stale_index.py` | `scripts/stale_index_check.py` блокує коміт, що повертає файл назад через відсталий індекс |
| `test_mononorm_sync.py` | `mcp/mononorm.js` дорівнює джерелу `desktop/dist/mononorm.js`; мовчазний дрейф дав би різні категорії в апці та MCP |

Проби, що потребують реального Flex-звіту IBKR, у репозиторій не
включені: вони працюють із приватними даними автора.
