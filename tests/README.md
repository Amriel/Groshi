# Проби

Сценарії на Playwright: відкривають зібраний файл, роблять те саме, що
робила б людина, і друкують результат. Кожна написана під конкретний
випадок і лишилась у репозиторії як сторож — щоб та сама поломка не
повернулась тихо.

```bash
npm install playwright && npx playwright install chromium
python3 app/build_app.py          # проби працюють із ЗІБРАНИМ файлом
node tests/allcheck.mjs
```

Якщо chromium уже є в системі, шлях до нього можна передати змінною:
`CHROMIUM=/usr/bin/chromium node tests/allcheck.mjs`.

| Проба | Що сторожить |
|---|---|
| `allcheck.mjs` | усі вкладки відкриваються без помилок у консолі |
| `empty.mjs` | порожня апка (свіжа установка) не падає на жодній вкладці |
| `gaps.mjs` | картки не злипаються: зазор між сусідніми ≥ 8 px |
| `glass2.mjs` | скляний шар не лишає «привидів» при скролі й не малює кадр під час руху |
| `notrans.mjs` | перемикання вкладок не смикає розмітку |
| `scrn.mjs` | режим скріншоту маскує суми на всіх вкладках |
| `pjstat.mjs` | стани проєкту: цикл чіпом, дата оплати, KPI |
| `pjui.mjs` | групи клієнтів у кошторисах розділені візуально |

Проби, що потребують реального Flex-звіту IBKR, у репозиторій не
включені: вони працюють із приватними даними автора.
