Сторінка може сповістити лише поки вона відкрита — це обмеження браузера, а не налаштування. Щоб нагадування приходили й тоді, коли апку закрито, експортуйте підписки в календар: у файлі є правило повтору й будильник за вказану кількість днів.

Порадник доступний лише в десктопній версії

Він працює через Claude Code на цьому комп'ютері, а браузерна версія не має доступу до програм системи. Відкрийте застосунок «Гроші» для Windows.

Перевіряю, чи встановлено Claude Code…

Claude Code не знайдено

  1. Встановіть Node.js (nodejs.org, версія LTS).
  2. У терміналі виконайте npm install -g @anthropic-ai/claude-code.

ПриватБанк — виписка

Приват API для фізосіб не дає, але виписку віддає файлом: Приват24 → Мої рахунки → Виписка → Експорт → CSV. Імпортуйте її сюди — операції стануть поруч із Monobank, правила категорій діятимуть і на них. Повторний імпорт того ж періоду безпечний: однакові операції не дублюються.

Категорії і правила

Як операції потрапляють у категорії та що рахується витратами

▾

Власні категорії

Правило: якщо операція підпадає під умови — призначити категорію. Умови необовʼязкові й діють разом. Сума розуміє 5919, >2000, 5000-6500, ~5900 (±10%). Правила мають вищий пріоритет за MCC.

Не рахується як витрати

У «Категоріях» натисніть ⊗ на будь-якому рядку — категорії, підкатегорії чи мерчанті — і він перестане потрапляти в суму витрат. Операції нікуди не зникають, лише не рахуються.

Перекази
Перекази між своїми рахунками

Переказ самому собі — не заробіток і не витрата. «Сховати повністю» прибирає зі списків лише перекази між власними рахунками — зняття готівки й поповнення банок залишаються на видноті. «Не рахувати» тримає поза підсумками, як і раніше, все разом: перекази, готівку і банки. «Рахувати як звичайні» рахує перекази людям і готівку. Перекази між власними рахунками й інвестиції не рахуються витратами ніколи.

Робочі витрати (ФОП)

Категорії, на які ви витрачаєте для роботи, — наприклад, оренда GPU і софт. Порадник рахує їх окремо від особистих і радить економію насамперед на особистому. На «Огляді» вони лишаються у витратах. Поодинокий особистий платіж перенесіть в іншу категорію в картці операції.

Приватність і замок

Що дозволено надсилати назовні і хто бачить дані

Зовнішні сервіси

Необов’язкові запити вимкнені, доки ви їх не дозволите. Банк і брокери працюють окремо за вашими підключеннями. Зовнішній сервіс бачить вашу IP-адресу та запит. Збережені дані можна переглядати без цих дозволів.

Замок
Код на вхід
Необовʼязково. Коли ввімкнено, апка при запуску питає код — щоб той, хто сів за компʼютер, не побачив ваші операції одним кліком.
Блокувати після … хв
Без дій у застосунку. 0 — тільки при запуску.
хв

Це не шифрування: файли з даними лишаються на диску як були, і той, хто знає, де вони, прочитає їх повз апку. Забутий код скидається видаленням pinHash у файлі стану.
